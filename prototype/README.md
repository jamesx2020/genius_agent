# 筑序 工程协同交互原型

根据 [系统设计稿](../doc/工程项目协同Agent系统设计稿.md) 制作的本地静态原型，无需安装前端依赖。

## 打开方式

直接用浏览器打开 `index.html`，或在项目根目录运行：

```bash
python3 -m http.server 8765 --directory prototype
```

访问 http://localhost:8765 。

## 页面与交互

- 项目总览：指标、风险提示、任务、岗位协作与动态。
- 协同任务：状态筛选、搜索和详情。
- 发起协同：选择三类场景，填写需求，记录附件文件名，生成演示任务。
- 流程详情：查看电缆延期案例的岗位分析、证据和执行步骤。
- 人工审批：切换方案、填写意见、批准或退回、模拟重新提交。
- 项目资料：查看四类演示证据。
- 独立演示登录：项目经理 `pm`、采购 `buyer`、财务 `finance`，统一密码 `demo123`。
- 各角色拥有独立工作台，顶部支持退出登录，不提供直接切换岗位。
- 项目经理批准或退回交付方案；采购查看结果、补充后重新提交；财务核对单据并生成付款申请草稿。
- 登录状态按标签页保存，业务数据在同浏览器共享并同步，可打开三个标签页分别体验。
- 登录与权限仅为前端演示，正式系统需要服务端认证与授权。
- 重置演示：恢复初始状态。

任务和审批状态仅保存在当前浏览器的 localStorage 中。文件不会上传；不调用真实模型，不连接 ERP，不执行真实采购或付款。新增任务展示待补资料状态，完整分析与审批体验使用预置电缆延期案例。

页面支持桌面与移动端布局，不依赖外部字体、图片或 CDN。
